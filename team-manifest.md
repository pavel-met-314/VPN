# TEAM-MANIFEST.md — правила мультиагентной работы над Family VPN

## Роли

- **Тимлид (это я, пользователь):** принимает решения, разбивает задачи, утверждает интерфейсы, собирает код.
- **Архитектор (AI в главном чате):** помогает разбивать проект, проектирует контракты, проверяет совместимость, не пишет код продакшена (только схемы и примеры).
- **Разработчик N (AI в отдельной сессии):** получает конкретную подзадачу, реализует её строго по контракту, возвращает код (или дифф), не трогает другие модули.

## Общие правила

1. Все публичные интерфейсы фиксируются в файле `contracts.md` (создаётся архитектором).
2. Каждый разработчик работает только в своей области, не изменяет чужие файлы.
3. Код должен быть самодостаточным, с комментариями на русском (кратко).
4. Если требуется изменить контракт — разработчик сообщает тимлиду, тот обновляет `contracts.md` и уведомляет всех.
5. Перед сдачей — разработчик предоставляет минимальный тест (или пример использования) для проверки интерфейса.
6. Все ответы — на русском, код — на английском (имена, ключевые слова).
