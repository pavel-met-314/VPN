# Этап 8: Второй VPS (запасной узел)

**Цель:** убрать единую точку отказа. Если Reality на первом IP режут/лагает —
клиент автоматически переключается на второй (Clash `url-test` → группа AUTO).

Портал уже умеет: в `config.yaml` блок `extra_nodes` → Clash/Hiddify подписка
получает оба узла.

## 8.1 Купить VPS

Рекомендации:
- **другой провайдер** и желательно **другая страна/AS**, чем текущий (Финляндия);
- от 1 vCPU / 1 GB RAM / 20 GB SSD;
- публичный IPv4;
- ОС Ubuntu 22.04.

Запиши: IP, root/user SSH, локацию (для имени узла, напр. `VPN-DE`).

## 8.2 Поднять на новом VPS тот же стек

По существующим этапам репо (укороченно):
1. hardening + SSH-ключ (`01`, `02`);
2. 3X-UI на `127.0.0.1` + VLESS+Reality на 443 (`03`);
3. те же 10 клиентов `user01`…`user10` с **теми же UUID**, что на первом сервере
   (иначе у семьи два разных профиля). UUID копируй из панели первого VPS
   или из бэкапа `x-ui.db`.

Reality `privateKey`/`publicKey`/`shortId` на втором сервере будут **свои** —
это нормально. В подписку пойдёт полный `vless://` со своими ключами.

## 8.3 Забрать vless-ссылку второго узла

Из панели второго VPS (или портала, если поставишь) скопируй `vless://…`
для `user01` (и проверь, что UUID совпадает с первым сервером).

## 8.4 Вписать в портал первого VPS

В `/etc/family-portal/config.yaml` на **основном** сервере:

```yaml
extra_nodes:
  - name: "VPN-DE"   # короткое имя в Clash
    vless_link: "vless://UUID@IP2:443?..."
```

```bash
sudo systemctl restart family-portal
```

Обнови подписку в Clash Verge → появится группа **AUTO** (url-test) и узлы.
Режим: группа `VPN` → выбери `AUTO`.

## 8.5 Проверка

1. Clash → Proxies → AUTO показывает оба узла, latency.
2. Выключи x-ui на первом VPS (`sudo systemctl stop x-ui`) — через ~5 мин
   url-test должен уйти на второй (или сразу вручную переключи).
3. Включи обратно.

## Ограничения

- Два сервера = двойная аренда.
- UUID клиентов надо синхронизировать вручную (или скриптом позже).
- Биллинг/expiry сейчас пишет только в `x-ui.db` **основного** сервера —
  на втором expiry пока не синхронизируется. Для семьи на старте ок:
  второй узел — аварийный канал; при массовом переезде копируй БД.
