# Этап 6: Раздача конфигов семье

**Цель:** каждый член семьи подключается без знания Linux.

Инструкции для родственников: [`clients.md`](../clients.md) — перешли им файл или ссылку на него.

## 6.1 Подготовка (админ)

1. SSH-туннель к панели ([05-admin.md](05-admin.md))
2. Inbound `family-reality` → список клиентов `user01`…`user10`
3. Для каждого человека — свой клиент (не один на всех)

## 6.2 Три способа выдачи

### A. Subscription URL (рекомендуется)

В панели 3X-UI:

1. **Panel Settings** → включи **Subscription** (если выключена)
2. У клиента → иконка **Subscription** / **Sub link**
3. Скопируй URL — отправь человеку (Signal, личный чат)

Плюсы: смена UUID — клиент обновит конфиг сам (pull to refresh).

### B. QR-код (мобильные)

1. Клиент → **QR Code**
2. Сфотографируй экран или отправь скрин **лично**
3. Не публикуй в общих чатах

### C. Ссылка vless:// (резерв)

1. Клиент → **Copy link** / иконка ссылки
2. Отправь текстом
3. На Android/iOS: открыть в v2rayNG / Streisand

## 6.4 Проверка у каждого

Попроси после настройки:

1. Включить VPN
2. Открыть https://2ip.ru
3. Скрин IP (должен быть VPS) — или просто «работает»

| Windows | Hiddify |
| macOS | Hiddify / Nekoray |
