# Этап 5: Админ-доступ и политика пользователей

**Цель:** ты управляешь панелью безопасно; семья — только клиентами.

## 5.1 SSH-туннель к панели

На Windows (PowerShell), подставь порт панели из установки 3X-UI:

```powershell
ssh -i "$env:USERPROFILE\.ssh\family_vpn" -L 8080:127.0.0.1:ПОРТ_ПАНЕЛИ vpnadmin@ВАШ_IP
```

Окно не закрывай. В браузере:

```
http://127.0.0.1:8080/WEB_BASE_PATH
```

`WEB_BASE_PATH` — случайный путь из установки (например `/aBcDeF/`). Без него панель не откроется.

## 5.2 Сменить пароль панели

В панели: **Panel Settings** → смени логин и пароль.

Требования:
- 16+ символов
- Храни в менеджере паролей (не в git, не в чатах)

## 5.3 Политика пользователей

| Правило | Зачем |
|---------|-------|
| 1 UUID = 1 человек | Отключение без затрагивания остальных |
| Remark: имя (`ivan`, `mama`) | Понятно кого отключать |
| Limit IP: 2 | Телефон + ноут, не раздавать друзьям |
| Без лимита трафика | Для семьи обычно не нужен |

## 5.4 Чеклист «что делать если»

### Новый телефон у члена семьи

1. Тот же subscription URL или QR — импорт на новое устройство
2. Или: панель → клиент → QR / ссылка

### Утечка QR / ссылки

1. SSH-туннель → панель
2. Inbound `family-reality` → клиент → **Reset UUID** или удалить и создать заново
3. Выдать новый QR/subscription

### Отключить человека

1. Панель → клиент → выключить (toggle) или удалить
2. Сохранить — Xray перезагрузится автоматически

### Потерял доступ к панели

1. SSH на VPS: `sudo x-ui` → сброс пароля / просмотр настроек
2. Проверить bind: `ss -tlnp | grep x-ui` → должен быть `127.0.0.1`

### Панель случайно на 0.0.0.0

```bash
sudo bash 03-bind-panel-localhost.sh
```
