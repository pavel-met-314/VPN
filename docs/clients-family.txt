================================================================================
  СЕМЕЙНЫЙ VPN — ИНСТРУКЦИЯ ДЛЯ ПОДКЛЮЧЕНИЯ
================================================================================

Это личный VPN для семьи. Конфиг = доступ к интернету через сервер.
Не пересылай QR, ссылки и подписки посторонним.


--------------------------------------------------------------------------------
1. ЧТО ТЫ ПОЛУЧИШЬ ОТ АДМИНА
--------------------------------------------------------------------------------

Достаточно ОДНОГО способа (админ выберет):

  A) QR-код          — лучший вариант для телефона
  B) Ссылка vless:// — можно вставить вручную
  C) Ссылка подписки — http://... (обновление конфига в приложении)

У каждого человека СВОЙ конфиг (user01, user02, ...).
Один конфиг на двоих — только если админ так разрешил.


--------------------------------------------------------------------------------
2. КАК ПРОВЕРИТЬ, ЧТО VPN РАБОТАЕТ
--------------------------------------------------------------------------------

1) Включи VPN в приложении (кнопка подключения / переключатель).
2) Открой в браузере:  https://2ip.ru
3) Должно показать:
   - IP НЕ твой домашний (не провайдер Wi‑Fi)
   - страна: Финляндия (или другая, куда поставлен сервер)

Если 2ip.ru не открывается — см. раздел 7 «Проблемы».


--------------------------------------------------------------------------------
3. ANDROID (РЕКОМЕНДУЕТСЯ: v2rayNG)
--------------------------------------------------------------------------------

Приложение: v2rayNG (Google Play или GitHub releases)
Ссылка Play: https://play.google.com/store/apps/details?id=com.v2ray.ang

--- Способ A: QR-код (проще всего) ---

1) Установи v2rayNG.
2) Открой приложение.
3) Нажми «+» (плюс) в правом верхнем углу.
4) Выбери «Import config from QR code» / «Сканировать QR».
5) Наведи камеру на QR от админа.
6) Появится профиль (например family-reality-user01).
7) Нажми на профиль — внизу кнопка «V» (подключение).
8) Проверь https://2ip.ru

--- Способ B: ссылка vless:// ---

1) Скопируй ссылку vless://... от админа.
2) v2rayNG → «+» → «Import config from clipboard» / «Из буфера».
3) Подключись (кнопка V).
4) Проверь https://2ip.ru

--- Настройки Android (если «нет интернета») ---

Настройки телефона → Сеть → Частный DNS (Private DNS):
  → ВЫКЛ или «Автоматически»
  → НЕ ставь dns.google и не свой DoH

В v2rayNG → Настройки → DNS:
  → Remote DNS: 8.8.8.8 (или оставь по умолчанию)

Режим маршрутизации: «Глобальный» / Global (весь трафик через VPN).


--------------------------------------------------------------------------------
4. ANDROID (АЛЬТЕРНАТИВА: v2RayTun)
--------------------------------------------------------------------------------

Если админ дал конфиг под v2RayTun:

1) Установи v2RayTun.
2) Импортируй vless:// ссылку или QR.
3) Подключись.

ВАЖНО: в ссылке адрес должен быть 2.26.9.208, НЕ localhost и НЕ 127.0.0.1.
Если в ссылке localhost — попроси админа новый QR/ссылку.

Если ошибка «Failed to decode selected config» — попроси QR, не ссылку,
или используй v2rayNG (раздел 3).

5. iPhone / iPad
--------------------------------------------------------------------------------

Приложения (любое одно):
  - Streisand (App Store, бесплатно)
  - FoXray
  - Shadowrocket (платное)

--- QR-код ---

1) Установи приложение.
2) «+» → Scan QR Code / Сканировать.
3) Подключись.
4) https://2ip.ru

--- Подписка (если дали http://...) ---

1) «+» → Add Subscription / Import from URL.
2) Вставь ссылку → Save.
3) Обнови список (pull to refresh).
4) Подключись.


--------------------------------------------------------------------------------
6. WINDOWS
--------------------------------------------------------------------------------

Два рабочих варианта.

--- Вариант A: v2rayN (проще) ---

Приложение: v2rayN (скачать с GitHub releases, Windows x64)

1) Установи / распакуй v2rayN.
2) Импорт:
   - QR: Servers → Import from QR code
   - или вставь vless:// из буфера
3) Запусти от имени администратора (правый клик → Run as administrator).
4) Выбери профиль → Start / Подключить.

Прокси только для браузера (Firefox):
  - v2rayN должен быть запущен (внизу: Local mixed:10808).
  - Firefox → Настройки → Сеть → Настройки подключения:
      Ручная настройка прокси
      SOCKS5: 127.0.0.1  порт 10808
      Галочка «DNS через SOCKS5» — ВКЛ
  - Открой https://2ip.ru

Весь ПК через v2rayN:
  - System proxy → Set system proxy
  - Или включи TUN (если работает без ошибок драйвера)

Если TUN падает с ошибкой Wintun/adapter — используй Clash Verge Rev (вариант B).

--- Вариант B: Clash Verge Rev (весь ПК, рекомендуется) ---

Приложение: Clash Verge Rev (Mihomo)

1) Админ даст профиль (yaml) или ссылку на конфиг.
2) Profiles → Import (через http://127.0.0.1:... если локальный файл).
3) Включи профиль (Use / активный).
4) Home:
   - System Proxy: ON
   - TUN Mode: ON (для всего трафика)
   - Mode: Global
5) Проверка в cmd:  curl https://ifconfig.me
   Должен показать IP сервера (не домашний).

Перед тестом выключи v2rayN, чтобы не конфликтовали.

--------------------------------------------------------------------------------
8. ПОДПИСКА (subscription) — ЕСЛИ ДАЛИ ССЫЛКУ http://...
--------------------------------------------------------------------------------

Подписка удобна: админ обновил конфиг — ты потянул список вниз и всё.

В ссылке подписки НЕ должно быть:
  - 127.0.0.1
  - localhost

Должно быть что-то вроде:
  http://2.26.9.208:2096/sub/...

В приложении:
  - Import from URL → вставить ссылку
  - Обновить подписку (pull / refresh)
  - Подключиться

--------------------------------------------------------------------------------
10. ПРОБЛЕМЫ И РЕШЕНИЯ
--------------------------------------------------------------------------------

Симптом: «Подключено», но сайты не открываются
  → Android: выключи Private DNS
  → Проверь Address в профиле = 2.26.9.208
  → Переимпортируй QR заново
  → Попробуй мобильный интернет вместо Wi‑Fi (или наоборот)

Симптом: «Failed to decode» / не импортируется
  → Используй QR, не ссылку
  → На Android: v2rayNG вместо v2RayTun
  → Проверь, что ссылка начинается с vless://

Симптом: 2ip.ru показывает домашний IP
  → VPN не включён или включён не тот профиль
  → Windows: проверь System Proxy / TUN в Clash
  → Firefox: проверь SOCKS5 127.0.0.1:10808 если используешь ручной прокси

Симптом: раньше работало, сейчас нет
  → Обнови подписку (pull to refresh)
  → Или попроси админа новый QR
  → Напиши админу (раздел 11)


--------------------------------------------------------------------------------
11. ЧТО НАПИСАТЬ АДМИНУ, ЕСЛИ НЕ РАБОТАЕТ
--------------------------------------------------------------------------------

Отправь:
  1) Какое приложение (v2rayNG / v2RayTun / Streisand / v2rayN / Clash)
  2) QR или подписка или vless://
  3) Скрин ошибки (если есть)
  4) Wi‑Fi или мобильный интернет
  5) Результат https://2ip.ru (какой IP показывает)
  6) Твой логин в VPN: user01 / user02 / ... (какой конфиг дали)

Не отправляй конфиг в общие чаты и группы.


--------------------------------------------------------------------------------
12. ЧАСТЫЕ ВОПРОСЫ
--------------------------------------------------------------------------------

Можно на два телефона одним конфигом?
  → Спроси админа. Обычно до 2 устройств на одного человека.

VPN заменяет интернет?
  → Нет. Нужен обычный интернет (Wi‑Fi/мобильный). VPN идёт поверх него.

Батарея садится быстрее?
  → Да, немного. Это нормально.

Можно раздавать конфиг друзьям?
  → Нет. Только для семьи.

Нужно ли что-то настраивать каждый день?
  → Нет. Включил VPN — пользуешься. Выключил — обычный интернет.
