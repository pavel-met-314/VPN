# Подключение для семьи

Инструкция для родственников — можно переслать как есть.

## Что ты получишь от админа

Один из вариантов (достаточно одного):

1. **QR-код** — отсканировать в приложении
2. **Ссылку подписки** (начинается с `http...`) — вставить в приложение
3. **Ссылку `vless://...`** — открыть или скопировать в приложение

**Не пересылай конфиг посторонним** — это личный доступ.

---

## Android

**Приложение:** [v2rayNG](https://play.google.com/store/apps/details?id=com.v2ray.ang) (бесплатно)

### QR-код

1. Установи v2rayNG
2. Нажми **+** → **Import config from QR code**
3. Отсканируй QR
4. Нажми на профиль → кнопка подключения (V)

### Подписка

1. **+** → **Import config from URL**
2. Вставь ссылку от админа → OK
3. Потяни список вниз для обновления
4. Подключись (V)

---

## iPhone / iPad

**Приложение:** Streisand (App Store) или FoXray / Shadowrocket (платные)

### QR-код

1. Установи приложение
2. **+** → Scan QR Code
3. Подключись

### Подписка

1. **+** → Add Subscription / Import from URL
2. Вставь ссылку → Save → обнови список
3. Подключись

---

## Windows

**Приложение:** [Hiddify](https://github.com/hiddify/hiddify-app/releases) или v2rayN

### Hiddify + подписка

1. Скачай и установи Hiddify
2. **New Profile** → вставь subscription URL
3. Выбери профиль → Connect

### v2rayN + QR

1. Скачай v2rayN с GitHub releases
2. **Servers** → **Import from QR code** (или clipboard для `vless://`)
3. Enter для подключения

---

## macOS

**Приложение:** Hiddify или Nekoray

Аналогично Windows: subscription URL или импорт `vless://`.

---

## Как проверить, что VPN работает

1. Включи VPN в приложении
2. Открой в браузере: https://2ip.ru
3. IP и страна должны совпадать с локацией VPS (не домашний провайдер)

Если не работает:

- Выключи и включи VPN
- Проверь Wi‑Fi / мобильный интернет без VPN
- Напиши админу — возможно, нужен новый QR

## Частые вопросы

**Можно на два телефона?** — Спроси админа; обычно да, до 2 устройств.

**Нужен ли постоянный интернет?** — Да, VPN не заменяет интернет, а идёт через него.

**Батарея** — на мобильных VPN немного разряжает быстрее; это нормально.
