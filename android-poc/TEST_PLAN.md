# Android — проверка и приёмка

Дата: 02.10.2026. Это локальная тестовая сборка, не стабильный опубликованный релиз.
Приватные адреса, credentials, профили и логи ядра в отчёт не включать.

## Автоматические проверки

- `:app:testDebugUnitTest`: стабильность канала, versionCode, некорректные метаданные,
  HTTPS/redirect hosts, конфликт allowlist/denylist, повреждённая контрольная сумма.
- `:app:assembleDebugAndroidTest`: Android JSON и PackageManager без тестовых libraries.
  `ClientSmokeInstrumentation` запускается только в disposable debug-приложении без
  сохранённого API-профиля и JSON. Проверяет строгие JSON numbers, ABI, исключения,
  удалённые приложения, конфликт allowlist, неизменность импорта и ping при выключенном VPN.
  Дополнительно запускает реальный главный экран: пароль скрыт по умолчанию,
  глазик показывает/скрывает текст, выделение сохраняется, recreation очищает
  пароль; кнопка назад в Settings — ImageButton, возвращающая на главный экран.
- `assembleDebug/lintDebug`, `assembleRelease/lintRelease`, `git diff --check`.
- Подпись v2/v3 и совпадение сертификата с опубликованной 0.1.0-alpha.1;
  versionCode 4, versionName 0.1.0.3, release не debuggable, ARM64 и license assets.
- update.json и SHA256SUMS должны соответствовать подписанной APK.

Пример запуска instrumentation на выбранном эмуляторе, после установки debug и test APK:

```powershell
& adb -s '<emulator-id>' shell am instrument -w `
  com.familyvpn.android.debug.test/com.familyvpn.poc.ClientSmokeInstrumentation
```

Тестовые файлы создаются в приватном хранилище debug-приложения и удаляются самим
тестом. Уже существующий профиль/импорт тест не перезаписывает: вместо этого он
останавливается. На телефоне семьи этот harness не запускать.

## UI на эмуляторе Android 16

- Светлая/тёмная темы: главный экран и Settings, читаемость, прокрутка, системные отступы.
- ru/en: все основные подписи, кнопки, ошибки и уведомления. Выбор сохраняется после
  нового открытия. Переключение темы/языка не вызывает дополнительный refresh.
- Увеличенный шрифт: кнопки не обрезаются; выбор языка становится вертикальным.
- Маскирование и показ пароля; пароль не сохраняется при recreation/process restart.
- App traversal: реальный перечень, поиск, системный переключатель, флажки, Apply,
  сохранение списка, корректное обозначение неприменённых изменений.
- Update: текущая версия, ручная проверка, ошибка сети/отсутствие стабильного релиза.

## Обязательные проверки на физическом телефоне

03.10.2026 проверена подписанная 0.1.0.4 на Samsung / Android 16.
Подробные результаты и границы проверки:
[PHONE_QA_2026-10-03.md](PHONE_QA_2026-10-03.md).
Вход/выход, реальный трафик на Wi-Fi и мобильной сети, пинг, потеря сети,
обход и снятие исключения при выключенном VPN проверены.
**Стабильный выпуск заблокирован:** Apply при активном VPN вызывает
`WindowManager.BadTokenException` и остановку туннеля. Полный цикл обновления,
суточное наблюдение и длительная работа остаются открыты.
Таблица ниже задаёт ожидаемое поведение; её строки не означают успешное прохождение.

Проверять именно подписанную APK. Подключить телефон к ПК по запросу тимлида.
Старый PoC, данные приложения и Hiddify не удалять.

| Сценарий | Ожидаемый результат |
| --- | --- |
| Вход, собственный профиль, выход | Поведение A1–A5 сохраняется; API-сбой не удаляет сохранённый профиль |
| Wi-Fi/мобильная сеть | Реальный трафик, DNS и выходной IP через VPS; сравнение с Hiddify |
| Пинг | HTTPS-проверка проходит через VPN, обновляется нажатием; без VPN — «—» |
| Ошибка пинга | «Недоступно», без автоматического отключения VPN |
| Смена сети | Старое значение сброшено; новое измерение через текущий туннель |
| Обход банка/браузера | Выбранное приложение выходит напрямую, контрольное — через VPS |
| Снятие исключения | После Apply приложение снова использует VPN |
| Apply при активном VPN | Предупреждение, краткий разрыв, новая конфигурация; без циклов переподключения |
| Сон, фон, длительная работа | Нет аварий/утечек; состояние ядра не заменяет проверку интернета |
| Уведомления | Разрешение/отказ, одно уведомление на новую стабильную версию, открытие Update |
| Суточное задание | Сохранено после reboot; принудительный QA-запуск и суточное наблюдение |
| Загрузка APK | Прогресс, отмена, ошибки сети и нехватки места; текущая установка сохранена |
| Установка | Проверка хеша/пакета/подписи, системное подтверждение, отмена без повторного открытия |
| Обновление поверх release | Прежний сертификат; профиль и настройки сохранены |

Для end-to-end Update нужен отдельно согласованный настоящий стабильный релиз
с корректными APK/update.json/SHA256SUMS/исходниками. Не публиковать искусственный
stable-релиз ради QA. Неверный хеш/подпись проверять изолированными fixtures,
не подменяя публичные release-assets.

Networking gate остаётся открытым до проверки этой матрицы и решения тимлида.
