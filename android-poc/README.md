# Family VPN Android networking PoC

Это экспериментальный клиент: локальный sing-box 1.14.2, Android `VpnService`,
вход через портал, Connect/Disconnect и состояние. Ручной импорт JSON сохранён
для проверки networking gate.
PoC принимает либо полный JSON с TUN, либо один VLESS-outbound из Hiddify.
Во втором случае он создаёт экспериментальный TUN/DNS/route в памяти;
это **не** эквивалент runtime-конфига Hiddify и не закрывает gate само по себе.
HTTPS API входа и выдачи профиля (`portal/app/client_api.py`) развёрнут
на VPS. Вход и загрузка собственного профиля проверены на телефоне
30 сентября 2026 года. Первая подписанная APK публикуется как тестовая
версия для семьи; Windows/iOS в этот PoC не входят.

## Безопасность

Рабочий JSON выбирается системным файловым диалогом и хранится только в
приватном хранилище приложения. Он не включается в APK, Git или журнал.
Профиль, полученный через API, и refresh token шифруются ключом Android
Keystore в приватном файле. Пароль портала не сохраняется.
PoC распространяется как тестовая версия; готовность к стабильному семейному
релизу ещё не подтверждена. `app/libs/libbox.aar` и генерируемый source JAR не
коммитятся; ядро собирается из закреплённого исходника sing-box.

## Сборка

Требуются JDK 17, Go 1.25.5, gomobile 0.1.12, Android SDK 36,
NDK 28.2.13676358 и Gradle 8.13. Сборка libbox закреплена
на теге `v1.14.2` sing-box (commit
`af6e64c3b69e6132ebaee0e1a3d24e93903f6709`). Клонируйте этот тег,
установите `gomobile` и `gobind` версии 0.1.12, выполните
`gomobile init`. Затем на Windows запустите `build-libbox.ps1` с путями
к исходнику sing-box и Android NDK. Скрипт проверяет commit, собирает
arm64 AAR в `app/libs/` и выводит SHA-256.

`gradlew.bat :app:assembleDebug` собирает отладочный APK. Подпись debug
подходит только для локального PoC. Приложение не устанавливает и не
изменяет другие VPN-профили на устройстве; активный профиль Hiddify следует
оставить для возврата к рабочему соединению.

## Вход через портал

Введите корневой HTTPS-адрес портала, например `https://<portal-host>`, затем
свой логин и пароль от сайта. Сервер выбирает профиль по учётной записи;
пользователь не выбирает чужие профили и не копирует VLESS-ссылку. Полученный
профиль сохраняется для подключения при временной недоступности API. Кнопка
`Sign out` отзывает сессию устройства и удаляет профиль при доступном сервере.
На тестовом телефоне проверены вход, загрузка профиля и короткие подключения
по Wi-Fi и 5G: внешний IP совпал с VPS, переключение Wi-Fi → 5G прошло
без аварии. После исправления отступов Android 16 все поля входа видны,
пароль маскируется. Ручной импорт остаётся контрольным способом подключения.
Длительная работа, сон устройства и полная сравнительная матрица ещё
не подтверждены; networking gate остаётся открытым.

## Проверка gate

На Android в Hiddify откройте меню карточки работающего профиля →
«Поделиться» → «JSON в буфер обмена». Сохраните содержимое буфера в
локальный файл на телефоне через текстовый редактор без облачной
синхронизации. Hiddify 4.1.1 экспортирует здесь только outbound с
credentials, а не полный runtime-конфиг; не пересылайте файл в чат.
Файл «Экспорт настроек» (`hiddify-options*.json`) не подходит: в нём нет
секций `inbounds` и `outbounds`. В PoC нажмите `Import local JSON` и
выберите сохранённый файл.

На одном устройстве и том же VPS сравните Hiddify и PoC с одним рабочим
JSON на Wi-Fi и проблемной LTE-сети. После Connect убедитесь в фактической
передаче трафика, DNS и выходном IP; повторите после сворачивания и
блокировки экрана. Не считать состояние ядра доказательством работы
интернета. Не отправляйте JSON, адреса серверов, подписки или логи ядра в
публичные отчёты. Если PoC уступает Hiddify, следующий этап блокируется до
анализа разницы поведения.

## Подписанная тестовая версия

Версия `0.1.0-alpha.1` (versionCode 2): Android 7.0+ и только ARM64.
APK публикуется в GitHub Releases вместе с SHA-256 и исходниками.
Используйте логин и пароль портала, а HTTPS-адрес получите у администратора.
После загрузки профиля нажмите Connect и разрешите создание VPN-подключения.

`build-release.ps1` собирает release APK, проверяет lint, выравнивает и
подписывает его постоянным ключом, затем проверяет подпись. Ключ и пароль
лежат вне Git в `%USERPROFILE%\.android\family-vpn-signing\`. Пароль
защищён Windows DPAPI и доступен только исходной учётной записи Windows;
резервную копию ключа необходимо сохранять вместе с доступом к этой записи.
Скрипт передаёт пароль через временную переменную окружения.

Release использует пакет `com.familyvpn.android`, новый debug-пакет —
`com.familyvpn.android.debug`. Релиз устанавливается рядом со старым PoC
`com.familyvpn.poc` и не переносит его профиль: войдите в новом приложении.
Последующие release-обновления подписываются тем же постоянным ключом
и устанавливаются поверх предыдущей release-версии.
